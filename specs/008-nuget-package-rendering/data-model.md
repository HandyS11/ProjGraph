# Data Model: NuGet Package Reference Rendering in `visualize`

## Entities

### `ProjectType` Enrichment

Update `ProjGraph.Core.Models.ProjectType` to include a new value:

- `Package = 4`: Represents an external NuGet package dependency.

### `Project` Record

The `Project` record will be used to represent NuGet packages. When representing a package:

- `Id`: A deterministic Guid generated by hashing the string `{PackageId}:{Version}` using SHA256. This ensures stable graph nodes.
- `Name`: The package ID (e.g., `Newtonsoft.Json`).
- `FullPath`: Stores the package version (e.g., `13.0.1`).
- `RelativePath`: Same as `FullPath` (the version string).
- `Framework`: The target framework version of the *first* project found referencing it.
- `Type`: `ProjectType.Package`.

### `SolutionGraph`

The `Projects` collection will now contain both projects and packages.
The `Dependencies` collection will contain `Dependency` records where:

- `SourceId` is the referencing project ID.
- `TargetId` is the deterministic package ID.
- `Type` is `DependencyType.PackageReference`.

## Relationships

- **Project -> Project**: `DependencyType.ProjectReference` (Existing, solid arrow `-->`)
- **Project -> Package**: `DependencyType.PackageReference` (New, dotted arrow `-.->` in Mermaid)

## Validation Rules

- **Direct Only**: Transitive package dependencies (packages depending on other packages) are NOT included.
- **Deduplication**: If multiple projects reference the same package + version pair, only one `Project` record with `ProjectType.Package` exists based on the deterministic ID. Diferent versions result in different nodes.

## Lifecycle / State Transitions

1. **Parsing Phase**: `ProjectParser` extracts `<PackageReference>` items and returns them in a tuple along with project references.
2. **Building Phase**: `BuildGraphUseCase` collects all unique package/version pairs if `includePackages` is true.
3. **Mapping Phase**: Packages are added as `Project` objects with `ProjectType.Package` using SHA256 hashing for the `Id`.
4. **Rendering Phase**: Renderers use the `Type` property and `DependencyType` to choose the appropriate visual style (Hexagons, Dotted Arrows, 📦 icons).
