## Summary

Build a cross-platform .NET 10 core library for parsing `.sln`, `.slnx`, and `.csproj` dependencies, exposed via a CLI tool and an MCP server. The core logic will reside in a standalone library (`ProjGraph.Lib`) to ensure reusability and testability, following the Clean Architecture pattern and the ProjGraph Constitution.
